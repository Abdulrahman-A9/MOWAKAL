# MOWAKAL

منصة عربية للخدمات القانونية تضم واجهة للعميل والمحامي ولوحة إدارة محدودة البيانات، وواجهة خلفية موثقة الصلاحيات.

## حالة التشغيل

الواجهة الحالية على Vercel ثابتة وتعمل بوضع العرض فقط ما دامت قيمة `frontend/api-config.json` هي `null`. لا تُحفظ الطلبات أو الرسائل في وضع العرض. **إضافة الباك اند إلى المستودع لا تنشره تلقائيًا على Vercel**؛ يلزم استضافته مع قاعدة MySQL 8، ثم ضبط عنوانه في ملف إعداد الواجهة وإعادة نشر الواجهة. لا تستخدم بيانات عملاء حقيقية قبل إكمال ذلك والاختبار على البيئة المنشورة.

## التشغيل المحلي

1. أنشئ قاعدة بيانات MySQL 8 فارغة وشغّل [المخطط](database/001_initial.sql) عليها. هذا المخطط مخصص لقاعدة جديدة فقط، ولا يرحّل قاعدة قائمة.
2. في `backend/` انسخ `.env.example` إلى `.env` محليًا، واضبط اتصال قاعدة البيانات و`JWT_SECRET` عشوائيًا بطول لا يقل عن 32 حرفًا و`FRONTEND_ORIGINS` بعنوان الواجهة. لا ترفع `.env` إلى Git.
3. شغّل `npm ci` ثم `npm start` من مجلد `backend/`. تحقق من `/api/health` و`/api/ready`؛ الأولى تتحقق من العملية والثانية من اتصال قاعدة البيانات.
4. أنشئ حساب إدارة أو مراجع توثيق من بيئة آمنة بتحديد `OPERATOR_NAME` و`OPERATOR_EMAIL` و`OPERATOR_PASSWORD` و`OPERATOR_ROLE` (`admin` أو `verifier`) ثم تشغيل `node scripts/create-operator.js` داخل `backend/`. لا يوجد حساب إداري افتراضي، ولا يسمح التسجيل العام بإنشائه. يفتح حساب المراجع صفحة `verifier/dashboard.html` بعد تسجيل الدخول، وهي منفصلة عن لوحة المدير.
5. اضبط `frontend/api-config.json` إلى `{ "apiBaseUrl": "http://127.0.0.1:3001" }` للتجربة المحلية فقط، ثم شغّل `python -m http.server 4173 --directory frontend` من جذر المشروع. لا تنسَ إعادة القيمة إلى عنوان API المنشور قبل نشر الواجهة. رابط الواجهة: `http://127.0.0.1:4173/`.

## نطاق التكامل

- التسجيل وتسجيل الدخول، الملف المهني للمحامي وتوثيقه، كتالوج الخدمات، طلبات العملاء، حالات الطلبات للمحامي المعيّن، الرسائل، المواعيد، وعرض محدود لإدارة الحسابات والخدمات والمؤشرات وأحداث التدقيق.
- الخادم يحدد هوية صاحب الطلب والرسالة من رمز الدخول، ويتحقق من الملكية والدور في كل مسار محمي. مدير المنصة لا يملك مسارًا لقراءة تفاصيل الطلبات أو الرسائل أو الملفات القانونية. مراجعة توثيق المحامين دور منفصل.
- صفحات القضايا والمستندات والمدفوعات والتقييمات وبعض وظائف التقويم لم تُربط بعد بالباك اند؛ تظهر كغير متاحة في الوضع المتصل، ولا يُدّعى حفظها. لا يوجد رفع ملفات فعلي حاليًا.
- وضع العرض الثابت ما زال موجودًا لأغراض استعراض الواجهة فقط، وليس مناسبًا لبيانات حقيقية.

## التحقق

من `backend/`: `npm test` لاختبارات حدود الصلاحية و`npm audit` لفحص الحزم. يلزم قبل تشغيل الإنتاج اختبار قاعدة MySQL حقيقية، إعداد TLS ونسخ احتياطية واستضافة API، ثم اختبار تدفقات الأطراف على البيئة المنشورة. لا تُخزّن الأسرار أو كلمات المرور في `frontend/`.
